    如何获取个人 Client ID（免费免审计）？

    1. 打开 Google Cloud Console 创建项目并启用 Google Drive API；
    2. OAuth 同意屏幕选 External（测试模式填自己/朋友 Gmail 为测试用户，或自己点 In Production 免 7 天重登）；
    3. 在 Credentials 创建 Desktop app（桌面应用） OAuth 客户端，把 Client ID 与 Client Secret 填入下方后点「连接 Google Drive」。
